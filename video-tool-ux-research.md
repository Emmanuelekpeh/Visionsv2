# UX & Workflow Research: Consumer Timeline Editors vs. AI Video Generators

For redesigning a local AI video-production UI. Claims are tied to source URLs; unverifiable items are marked "not verified."

---

## Family A — Consumer / browser timeline editors

### Layout

Four of the seven share one skeleton: **left asset rail + center preview + right inspector + bottom timeline**. CapCut desktop names them **Media & Assets Panel (top left)**, **Preview (top center)**, **Properties Panel (top right)**, **Timeline (bottom)**, described as the central non-linear workspace with multi-track editor and preview axis ([Filmora on CapCut](https://filmora.wondershare.com/advanced-video-editing/capcut-timeline.html); CapCut's own steps — Import → drag to timeline → Split → Export — confirm the arrangement, [CapCut](https://www.capcut.com/resource/how-to-use-capcut-on-pc)). Clipchamp documents the same four regions with more precise names: left **toolbar** (Your media, Record and create, Content library, Video templates, Text, Transitions, Brand kit), right **property panel**, a **floating toolbar above the preview**, and the timeline. The floating toolbar is contextual — with nothing selected it exposes whole-video controls (Size/aspect ratio, Background color, AI captions) ([Clipchamp](https://clipchamp.com/en/blog/how-to-navigate-video-editing-tools/)).

**Kapwing** is canvas-first: timeline at the bottom, layers as tracks, layer properties in a **right edit sidebar**. Image projects have **no timeline at all** until you set an output duration in the right-side **Timing** tab ([Kapwing](https://www.kapwing.com/help/timeline-tutorial/)).

**Descript inverts the layout.** The primary surface is the **Script editor**, alongside the **Scene editor**, a **Timeline**, and a right sidebar of Project / Scene / Layer / Elements / Media / AI Tools / Underlord panels; panels are resizable and the scene editor flips between side-by-side and stacked ([Descript](https://help.descript.com/descript-tour/the-editor-interface), [customize the editor](https://help.descript.com/descript-tour/customize-the-editor)).

**InVideo Editor** is a browser NLE with a **left-hand agent chat panel** that operates directly on the timeline, plus **Media**, **Monitor**, and timeline regions ([InVideo](https://help.invideo.io/en/articles/16819946-introducing-invideo-editor), [get started](https://help.invideo.io/en/articles/16920168-how-to-get-started-with-invideo-editor)). **VEED** is a dashboard (New Project + project list) into a workspace with a **left sidebar** for Subtitles/AI tools ([VEED walkthrough](https://www.fahimai.com/how-to-use-veed)). Canva's current video-editor panel naming was **not verified**.

### Onboarding

Two schools. **Blank canvas** (CapCut, Clipchamp, VEED) opens an empty project with Import highlighted, or a templates tab with preset aspect ratios and themed collections ([CapCut](https://www.capcut.com/resource/how-to-use-capcut-on-pc), [Clipchamp](https://clipchamp.com/en/blog/how-to-navigate-video-editing-tools/)). **Prompt-first** (Descript, Kapwing, InVideo, Canva) starts from an input box or an AI Video Maker. Descript's empty state offers *Upload a file / Generate from a prompt / Paste a script*, then voiceover, aspect ratio, and one of five visual styles ([Descript AI Video Maker](https://help.descript.com/ai-assistant/ai-video-maker)). Kapwing's homepage asks "What are you creating today" above a text box that accepts attachments ([Kapwing](https://www.kapwing.com/help/ai-video-generator/)). Canva's homepage prompt box carries `+` for Upload / Add from Canva / **Apply brand** ([Canva Magic Media](https://www.canva.com/help/using-magic-media/)).

Fastest to watchable: Kapwing's Kai (prompt → **storyboard preview** → approve → generate, [Kapwing](https://www.kapwing.com/ai/text-to-video)) or Descript's AI Video Maker, which yields a finished editable composition with no manual assembly. Canva's **Magic Video** builds a 60-second multi-scene vertical video from 1–10 clips plus a prompt ([Canva](https://www.canva.com/help/magic-video/)).

### Core loop and clicks to first export

The loop is near-identical everywhere: import → drag to timeline → trim/split → text/effects/music → export. Approximate counts derived from documented steps: CapCut manual **~6** (Create project → Import → select → drag → Export → Export); CapCut Instant AI video **~8** with zero editing skill (style → aspect → script → voice → Create → Export); Kapwing Kai **~4–5**; Descript AI Video Maker **~7** with an already-finished cut; InVideo Editor **~5**.

### Text/caption-first and script-first

**Descript is the reference implementation.** Its docs state the mechanism exactly: "This transcript isn't just a reference — it's directly linked to your media. Delete a word from the transcript, and that word disappears from your audio or video. Cut and paste a sentence, and the media moves with it." Three destructive verbs are separated: **Delete** (media + text), **Remove from transcript** (media kept, text hidden from captions/exports), **Ignore** (strikethrough, keeps text). A **wordbar** under the script sets per-word start/end; parenthetical **inline notes** annotate non-speech without breaking alignment. Bulk tools: filler-word removal, shorten word gaps, and **Regenerate** to heal jump cuts or change spoken words ([Descript: edit like a doc](https://help.descript.com/getting-started/edit-like-a-doc)). The structure above the transcript is the **scene**: "a segment of your video with its own visuals," shown as script thumbnails, timeline segments, and **storyboard tiles**; created by typing `/`, right-click **Add scene**, or **Split** ([Descript: scenes](https://help.descript.com/getting-started/scenes)).

**CapCut** works text-first from two directions: **Captions → Auto captions → language → Generate** then one-click styling, and **Instant AI video**, which takes a script (or **Generate script**), style, aspect ratio, voice and duration, then exposes a **Scenes** panel where you replace or regenerate any scene's media ([CapCut](https://www.capcut.com/resource/how-to-use-capcut-on-pc)). **Kapwing** ships explicit **Topic / Prompt / Script / Article / PDF-to-video** entry points with a 1,000-character limit ≈ 1–2 minutes of video, plus a **Trim with Transcript — "Edit videos by editing text"** tool ([Kapwing](https://www.kapwing.com/ai/text-to-video)). **VEED** is caption-first (Subtitles → Auto Subtitles → review → style → burn in or SRT; **Magic Cut** strips filler words, [VEED](https://www.fahimai.com/how-to-use-veed)). **InVideo**'s agent edits the timeline from prose — "cut this down to 60 seconds," "clean up the silences" — with "Every change shows up as real clips and cuts you can grab, reshape, or undo. Nothing is locked." ([InVideo](https://help.invideo.io/en/articles/16819946-introducing-invideo-editor)).

### AI integration and slow-generation UX

The decisive split is **inline vs. separate generation surface**.

Descript is the strongest inline design: "When you add a new empty scene, three options appear directly on the canvas. This is the quickest way to start generating media." Unsupported per-model parameters render as **disabled buttons**. Two documented gaps to avoid: prompts **don't carry over** between Image and Video tabs, and generation history is **separate per media type** ([Descript](https://help.descript.com/generative-media/generate-media.md)). Failures appear as a **checkered placeholder layer** in the document reading "Custom prompt required" / "Image generation rejected based on content," fixable by selecting the layer → **Add Media** — a genuinely good pattern worth copying. Descript's AI Video Maker states the wait plainly ("a few minutes… especially if an avatar is included") and delivers a new composition ([Descript](https://help.descript.com/ai-assistant/ai-video-maker)).

CapCut gates generation behind **AI media → AI video** in the left sidebar, with prompt, model (Seedance 1.0, Runway), duration, aspect ratio ([CapCut](https://www.capcut.com/resource/how-to-use-capcut-on-pc)). VEED uses an **AI tools panel** and a **Model Picker** for VEO 3 / Kling, then "send the generated clip to the timeline and trim it" ([VEED](https://www.fahimai.com/how-to-use-veed)).

Kapwing makes **chat the primary surface** — Kai is "a video editing agent," reachable from the sidebar, homepage, or the editor's AI tab, accepting up to 10 attachments, returning a **storyboard** (script, B-roll, aspect ratio, voiceover) for approval. Two design lessons: "once a video is generated, credits are consumed regardless of satisfaction," and a **credit estimate** is shown on the plan which you can push back on ("you can tell Kai to generate a new plan using less credits"). Prompt history persists under **Chats**, per-user not per-workspace ([Kapwing](https://www.kapwing.com/help/ai-video-generator/)).

### Templates, presets, reuse

CapCut: pro-templates, **Compound Clips** (right-click → Create Compound Clip) and clip **Grouping** to collapse timeline clutter. Clipchamp: **Video templates** + **Brand kit** (logos, palettes, fonts). Descript: **layout packs** with a drive-wide default, **Brand Studio**, **copy/paste attributes** reusing volume/zoom/color across clips, reusable visuals/media, and **prompt templates** ([Descript scenes](https://help.descript.com/getting-started/scenes), [docs index](https://help.descript.com/llms.txt)). Canva: Brand Kit, **Apply brand** as a prompt modifier, and Magic Video's **"Try a different vibe"** which restyles while keeping original media. Kapwing: **Brand Kit → Brand Characters** invoked as `@name` ([Kapwing](https://www.kapwing.com/help/ai-video-generator/)). VEED: Brand Kit, **share by URL** instead of review exports.

### Export

Descript exports video/audio/GIF/text/subtitles, exports the timeline **non-destructively** to other NLEs, publishes a standalone **share page** with embeddable player, or pushes to YouTube and podcast hosts — via two tabs, **Destination** and **Local export** ([Descript](https://help.descript.com/export-and-share/export-and-publishing-overview)). CapCut's dialog asks file name, location, resolution, bitrate, format, frame rate, codec. Kapwing switches output type among **MP4 / GIF / JPEG / MP3** with documented limits when visuals or audio are absent ([Kapwing](https://www.kapwing.com/help/timeline-tutorial/)). VEED burns in subtitles or exports **SRT**; free tier watermarks and caps length.

## Family B — AI video generation products

### Structure: what replaces the timeline

**Google Flow is the only one with both scene-level structure and an assembly timeline.** **Scenebuilder** lets you "Arrange multiple clips in a sequence, Rearrange the order, Trim the beginning and end of each clip with the handles, Preview the whole sequence, Download a scene" — clips enter via a clip's **More → Add to Scene**, then drag to reorder ([Flow](https://support.google.com/flow/answer/16935718?hl=en)). Layered on top: **Ingredients to Video** (multiple reference images controlling characters, objects, style), **Frames to Video** (start + end image bridged), **Extend** (continues from "the final second of your previous clip," reaching "a minute or more"), **Insert**, and an object-removal that reconstructs the background ([Google blog](https://blog.google/innovation-and-ai/products/veo-updates-flow/)). Ingredients are dragged in or referenced by typing `@`; voices via Add → Voices and `@Voice: Andrew`, valid **only on generations that use ingredients** ([Flow](https://support.google.com/flow/answer/16353334?hl=en)). Projects also carry a right-hand **History panel** of every prior version and prompt ([Flow](https://support.google.com/flow/answer/16935718?hl=en)).

**Runway's unit is the Session, not the scene:** "a folder or group of generations you create at a given time," streaming chronologically in the right pane, newest at bottom. Left nav: New Session, Home, Agent, Tool, Apps, Workflows, Recents, Projects, Assets, Favorited; Home puts an Agent prompt on top with `@` for References and `/` for Agent Skills plus **Presets** curated by onboarding answers ([Runway](https://help.runwayml.com/hc/en-us/articles/24298206897043-Navigating-Runway)).

**Kling** expresses shots *inside one prompt*: **Custom Multi-Shot** swaps the prompt area for a storyboard panel defaulting to "Shot1 at 2 seconds and Shot2 at 3 seconds," each with its own description, capped at **6 shots / 15 seconds**, each shot with its own duration, framing and camera movement ([Kling tutorial](https://www.genmedialab.com/fr/tutorials/how-to-use-kling-ai/)). **Sora's Storyboard** is per-scene cards: choose Storyboard in the composer, set duration and orientation, "add a prompt to each scene card," results land in **Drafts**. Limits: 10s default, 15s all users, 25s Pro; no frame-level timeline, so one bad moment means regenerating the sequence ([Filmora on Sora](https://filmora.wondershare.com/trending-topic/how-to-use-sora-2-storyboard.html)). **Luma** organizes by **Boards** (per-project groups) and **Ideas** (a global asset stream), toggled on the left ([Luma](https://lumalabs.ai/learning-hub/navigating-boards-ideas)). **Kapwing** is the hybrid: chat history *plus* an approved **storyboard** *plus* the full studio timeline for the result.

### Iteration knobs

**Runway Gen-4** requires an input image that "acts as the first frame," with the prompt describing **motion only**. 5s/10s; six aspect ratios; 24fps; 1000-char prompt cap; **Fixed seed** toggle (off by default) that accepts a pasted previous seed. Per-output **Use** menu: Use as Character/Performance in Act-Two, **Retime** (trim, speed, handheld shake, reverse — no credits), **Expand Video**, **Use Current Frame**, **Upscale to 4K**. Cost is per second: Gen-4 12 credits/s vs Turbo 5, with an explicit "explore in Turbo, then switch" recommendation ([Runway](https://help.runwayml.com/hc/en-us/articles/37327109429011-Creating-with-Gen-4)). References: up to **three** active per generation, `@` autocompletes a name, untagged images are **session-temporary** while **tag to save** persists them and **Share with Workspace** promotes them; **sketch a scene** produces a drawing/labeled Reference that "cannot be edited once exported" ([Runway](https://help.runwayml.com/hc/en-us/articles/40042718905875-Creating-with-Gen-4-Image-References)).

**Kling** offers six basic camera moves (horizontal, vertical, zoom, pan, tilt, roll) plus four **Master Shots** (move left/right and zoom in, move forward and zoom up, move down and zoom out), with a **displacement parameter** controlling extent ([Kling camera](https://kling.ai/quickstart/ai-camera-control-guide)). **Motion Brush** selects regions by auto-selection or brushing, draws **motion trajectories**, and supports **six elements with trajectories at once**; **Static Brush** pins pixels against camera drift. Documented traps: trajectories on immovable objects get reinterpreted as camera paths, and brushing only a sub-part (a dog's head) yields more precise control ([Kling motion brush](https://kling.ai/quickstart/how-to-animate-image-parts)). **Motion Control** takes a 3–30s reference motion clip (from History or the **Motion Library** preset gallery) plus a character image, with "Matches Video" vs "Matches Image" radio buttons.

**Luma:** **Keyframes** = start + end frame (uploaded or generated) with an optional guiding prompt; **Extend** accepts an **image keyframe** as destination, yielding up to **9 seconds** (and ~30s via keys/extend at some quality cost); **Loop** is a web toggle (infinity symbol) or, on iOS, a tag under "Playback" where tags are grouped into **Shots, Camera Angle, Style, Lighting** ([Luma keyframes](https://lumalabs.ai/learning-hub/how-to-use-keyframes), [Ray2](https://lumalabs.ai/learning-hub/dream-machine-how-to-generate-with-ray2)). **Pika** layers Pikaframes (start/end), Pikascenes (compose from elements), Pikadditions, Pikaswaps, Pikatwists, and Pikaformance (audio-driven lip-sync) ([Pika](https://aialleyway.com/pika-labs-review/)). **Kapwing** supports start/end frames, motion controls and multi-scene — the latter requiring Seedance plus the literal phrase **"the camera switches"** in the prompt.

### Queue / slow-generation UX

This is the weakest area in the whole survey and the clearest opportunity.

**Cost is shown before commit**, in two good patterns: Kling's Generate button literally displays the price and updates live (60 credits → 40 toggling Native Audio off), and Kapwing shows a rejectable **credit estimate** ([Kling](https://www.genmedialab.com/fr/tutorials/how-to-use-kling-ai/), [Kapwing](https://www.kapwing.com/help/ai-video-generator/)). **Queue behavior is punitive and explicit:** Kling's free queue "may refuse a new generation outright" at peak, with the upgrade screen offering only off-peak hours or a paid plan; the priority queue is advertised as **3 minutes** ([Kling](https://www.genmedialab.com/fr/tutorials/how-to-use-kling-ai/)). Pika's free queue measured **over twelve minutes** for one 480p 5s clip with an "Upgrade for faster generations" prompt on the loading card throughout ([Pika](https://aialleyway.com/pika-labs-review/)).

**Non-blocking queueing exists in exactly one place:** Runway — "Your generations will be scrollable through your session as you continue to generate," saved to **Assets** under the Session sub-folder ([Runway](https://help.runwayml.com/hc/en-us/articles/37327109429011-Creating-with-Gen-4)). **No vendor documents a percentage or ETA**; only qualitative waits (Luma 10–60s; Descript "a few minutes"). Sora Pro's "relaxed" videos are explicitly queued for low-traffic periods ([MIT Tech Review](https://www.technologyreview.com/2024/12/09/1108309/how-to-use-sora-openais-new-video-generating-tool/)). With 20 clips, Flow's Scenebuilder is the only in-family answer; Runway falls back to a chronological stream; everyone else implies download-and-leave.

### Continuity

**Referenced generation.** Runway's named References "excels at generating consistent characters across different lighting conditions," with an advanced workflow splitting a **character path** and a **scene path** then combining, and **Reference for image** promoting any output into the set. **Flow** uses `@CharacterName`, `@me`, `@Voice: Name` and dragged ingredients, advising plain/segmented backgrounds and consistent-looking ingredient sets. **Kling's Element Library** stores *typed* composite assets (Characters, Animals, Props, Costumes, Scenes, Special Effects, Others); a multi-image element needs **2–4 references** (1 main + up to 3 angles) and video character elements come from a **3–8s single-character clip** with optional **bound voice**. Elements are invoked with `@` or Add from Element Library; Kling 3.0 Omni accepts up to **7 images/elements** without video input (**4** with), Video 3.0 binds up to **3 elements** after start/end frames and "the elements must appear in the reference frames." Creation is **free**; library caps are 30 free → 50 → 150 → 500 ([Kling](https://kling.ai/quickstart/klingai-element-library-3-user-guide)). Kapwing's **Brand Characters** live in Brand Kit and are called as `@name`.

**Trained identity.** **Higgsfield Soul ID** is the sharpest articulation: "Train it once on 20 or more photos of one person (up to 80), and the same face appears across every generation," via **Soul → Train new character** → upload → minutes of training → select from the **Character tab**. It contrasts itself directly with per-generation references, which "anchor a single generation but drifts across many separate ones." Limits: "clearly the same person" not pixel-identical, **one person per Soul ID** (use Elements for two-handers), not exportable as a file ([Higgsfield](https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-create-and-use-a-soul-id-character)).

### Assembly and where users leave

In-family assembly is thin: Flow's Scenebuilder is the most complete; Sora's Storyboard has no frame-level timeline; Runway offers **Edit Studio**, Retime and Expand plus plugins that place generation *inside* Premiere Pro and After Effects timelines ([Runway](https://help.runwayml.com/hc/en-us/articles/37327109429011-Creating-with-Gen-4), [plugins](https://help.runwayml.com/hc/en-us/articles/55121421123987-Using-Runway-Plugins-in-Adobe-Premiere-Pro)). Kling's AI Video Editor page returned "This article has been removed" — **not verified** ([Kling](https://kling.ai/quickstart/ai-video-editor-guide)).

The reasons users leave are mechanical: published failure modes are identity drift, hand/prop contact failure, background geometry warping under camera motion, unprompted cuts, and artifact hallucinations — and the recommended response is to **reject the clip**, not grade or upscale it ([Higgsfield guide](https://www.frankx.ai/guides/higgsfield-ai-video-guide)). Duration is the second reason (Sora caps at 25s on Pro). The destination is always a timeline: Filmora pitches "place them on a full editing timeline… and layer multiple scenes into a longer video," with AI Extend and **Replace Clip** to swap one Sora scene without disturbing the rest ([Filmora](https://filmora.wondershare.com/trending-topic/how-to-use-sora-2-storyboard.html)). InVideo now exports "straight to MP4, or take the whole thing into Premiere Pro, Final Cut Pro, or DaVinci Resolve with your cuts intact" — and **imports** Premiere/Resolve projects ([InVideo](https://help.invideo.io/en/articles/16819946-introducing-invideo-editor)). Kapwing's positioning names the gap most cleanly: "Most AI video tools generate a clip and stop there. Kapwing doesn't… No export, re-import, or switching apps."

## What a small local AI video tool should steal

1. **The transcript as the primary document, with media as its projection** — deleting a word deletes the frames; cut/paste carries media ([Descript](https://help.descript.com/getting-started/edit-like-a-doc)). *Why: it collapses trim-and-arrange into text editing, the single biggest UX win here.*
2. **Three distinct verbs: Delete (media goes), Remove from transcript (media stays, text hidden), Ignore (strikethrough)** ([Descript](https://help.descript.com/getting-started/edit-like-a-doc)). *Why: users constantly need footage kept while words leave the captions.*
3. **A wordbar with per-word start/end handles beneath the transcript** ([Descript](https://help.descript.com/getting-started/edit-like-a-doc)). *Why: frame-level precision without ever showing a non-editor a frame grid.*
4. **Scenes shown simultaneously as script thumbnails, timeline segments, and storyboard tiles** ([Descript](https://help.descript.com/getting-started/scenes)). *Why: one object needs textual, temporal and spatial representations at once.*
5. **Generation placeholders that live in the document** — a checkered layer with an explanation, swappable via "Add Media" on the layer ([Descript](https://help.descript.com/generative-media/generate-media.md)). *Why: slow or rejected generations become repairable edit elements instead of lost requests.*
6. **The credit/time cost printed on the Generate button, updating live as settings change** ([Kling](https://www.genmedialab.com/fr/tutorials/how-to-use-kling-ai/)). *Why: expensive knobs (audio, 4K, extra outputs) become self-explaining and spend is never a surprise.*
7. **Return an editable storyboard for approval before spending credits, with a "do it cheaper" escape hatch** ([Kapwing](https://www.kapwing.com/help/ai-video-generator/)). *Why: generation is non-refundable, so the outline is the cheapest intervention point.*
8. **A named, saved reference/element library invoked inline with `@` autocomplete** ([Runway](https://help.runwayml.com/hc/en-us/articles/40042718905875-Creating-with-Gen-4-Image-References), [Kling](https://kling.ai/quickstart/klingai-element-library-3-user-guide), [Flow](https://support.google.com/flow/answer/16353334?hl=en)). *Why: continuity is the top quality complaint and `@` is its lowest-friction control.*
9. **Multi-image elements: 1 main reference + up to 3 angles, with AI auto-description; free to create, with visible library caps** ([Kling](https://kling.ai/quickstart/klingai-element-library-3-user-guide)). *Why: a single reference image is demonstrably what causes drift, and "give me other angles" is learnable.*
10. **References persistent by default via explicit "tag to save" plus a workspace-share toggle** ([Runway](https://help.runwayml.com/hc/en-us/articles/40042718905875-Creating-with-Gen-4-Image-References)). *Why: silently session-scoped references are a documented source of lost work.*
11. **Typed assets — Character / Animal / Prop / Costume / Scene / Effect — with optional bound voice** ([Kling](https://kling.ai/quickstart/klingai-element-library-3-user-guide), [Higgsfield](https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-create-and-use-a-soul-id-character)). *Why: typing teaches what consistency is achievable and keeps the library browsable rather than a junk drawer.*
12. **Shot-level storyboard with per-shot duration, framing and camera move, submitted as one generation** ([Kling](https://www.genmedialab.com/fr/tutorials/how-to-use-kling-ai/), [Sora](https://filmora.wondershare.com/trending-topic/how-to-use-sora-2-storyboard.html)). *Why: it is the missing link between prompt and timeline, making continuity a planning act.*
13. **Scenebuilder semantics: Add to Scene, drag to reorder, edge handles to trim, preview, download the scene** ([Flow](https://support.google.com/flow/answer/16935718?hl=en)). *Why: the minimum viable assembly UI, inside the generator rather than a round-trip.*
14. **Continuous generation into a live session gallery with a non-blocking queue** — outputs append chronologically while you keep prompting ([Runway](https://help.runwayml.com/hc/en-us/articles/24298206897043-Navigating-Runway)). *Why: it converts multi-minute waits into parallel work, the only honest answer to slow generation.*
15. **Per-second, per-model price tables plus a deliberately cheap "explore" model beside the expensive one, and non-destructive timeline export with a Premiere/Resolve import path** ([Runway](https://help.runwayml.com/hc/en-us/articles/37327109429011-Creating-with-Gen-4), [Descript](https://help.descript.com/export-and-share/export-and-publishing-overview), [InVideo](https://help.invideo.io/en/articles/16819946-introducing-invideo-editor)). *Why: users iterate 5–10× per accepted shot and will not accept being trapped, so the loop's cost and exit both decide retention.*
